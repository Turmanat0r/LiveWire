Tournament director sign-in

Signing in is what lets the tournament server accept director changes. It is tied to your account, not to this device.

Passcode only

Opens the panel on this device without signing in. Fine for looking around — but the passcode ships inside this page, so it is a latch, not a lock, and the server refuses changes made this way.

Positions

Where each angler's device last reported from. Positions are recorded when the app already had a fix — submitting a catch, or an angler checking themselves against the boundary — so nothing here drains a battery, and nothing is live. Read the age next to each one before you act on it.

Anglers cannot see each other here. The only position that goes out to the field is a raised beacon.

Event

Which tournament this app is running. Every device follows this setting, so change it once and the whole field moves together. Records stay attached to the event they were logged under — switching never mixes two fields, and switching back brings the first one up exactly as it was.

Scoring species

Every species this event scores. Anglers pick from this list or “Other (not scored)” when they submit, and only these are ranked, placed and paid. They share one leaderboard, ranked by length — so add a second species only when the two are worth comparing, or you are testing. Each ceiling is a sanity check for that species: a catch longer than it gets flagged for you, never rejected.

Course boundary

Where the event is fished. Every catch records whether it was taken inside this line. Draw it on the map or type the numbers — either way it is the same boundary, and anglers can check themselves against it from the GPS screen.

Re-check logged catches

Each catch was judged against the boundary that was set when it was logged. If you have changed the boundary since, this re-runs every catch against the current one using the position already stored with it. Nothing is approved, rejected or deleted — only the in/out reading changes.

All events

Everything this app knows about, and what each one holds. Archiving takes an event out of the switcher without touching a single record — restore it and it comes back exactly as it was.

Add an event

Set up next year’s tournament without touching the code. Nothing about the live event changes until you switch to the new one.

Anglers are numbered from 1 for each event, so the prefix is what keeps this year’s entry 001 apart from last year’s. It has to be unique.

Results

The trophy case works everything out again from the catches every time it opens. That is right while the event is running and wrong once it is over — a later cleanup would quietly rewrite what an angler’s trophy case says about this year. Freezing writes the placings, the Big Fish pot and the settled side bets down once, and the trophy case reads those from then on.

Contestants

Every registered angler with their live stats and standing. Disqualifying removes an angler from the standings, the Big Fish pot, and payout placements — their entry fee stays in the pool.

GPS check

Reviews the location saved with every submitted catch. An unavailable or outside-course location is flagged for director review, never automatically rejected.

Payout calculator

Auto-calculated from the final roster, plus any donations logged below. Each division uses a 50/30/20 split. The optional $10-per-angler Big Fish pot is winner take all.

Planned awards budget

What you plan to spend on trophies, plaques, or other hardware — kept separate from the cash pools above. Not shown to anglers.

Add a donation
